# Analytics events

The event × field matrix for Pathfinder's RudderStack events. It records which shared ("envelope") fields each `pathfinder_*` event carries, so a reader can follow one user across events without per-event stitching. [`TELEMETRY.md`](TELEMETRY.md) explains the pipelines and privacy rules; this page is the per-event field reference.

**Ownership.** The analytics team owns this contract and the warehouse models built on it. The plugin team owns the instrumentation code (`src/lib/analytics.ts` and its call sites). A PR that adds an event, or adds, renames or re-values a property, updates this page in the same PR and requests a review from the analytics team.

> **Status: draft for review.** Generated from the properties the warehouse has received for each event, not from reading the code. A ✅ means the property has arrived at least once; it may since have been dropped, or be sent only on some code paths. Check before relying on a cell.

## Fields on every event

These come from Grafana's RudderStack backend or from `reportAppInteraction`, so they're not repeated in the matrix:

- **Who / when:** `user_id`, `anonymous_id`, the event timestamp, and RudderStack's browser session (`context.sessionId`: 30-minute inactivity timeout, not unique on its own, so pair it with `anonymous_id`).
- **Where in Grafana:** the page URL and path.
- **Run context:** `plugin_version`; `variant` and `experiments` while the user is enrolled in an experiment (not on `feature_flag_evaluated`).
- **Kiosk:** `kiosk_session_id` and `kiosk_name` while a kiosk session is active.
- **Panel session:** `pathfinder_session_id` (with `session_started_at` on the first event) while a Pathfinder surface is open, once #2223 ships.

`feature_flag_evaluated` is not a user action and is left out of the matrix.

## Legend

| Mark      | Meaning                                                                                                                               |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| ✅ `name` | Sent, under the property named                                                                                                        |
| D         | Not sent, but derivable downstream: from the locator (`content_url` / `source_document`) or the resource id via the published catalog |
| ➕        | Not sent and not derivable; a candidate for the plugin to add                                                                         |
| (blank)   | Not applicable to this event                                                                                                          |

## Columns

- **resource id:** `guide_id`, `journey_id` or `path_id`.
- **source / visibility:** `guide_source` and `guide_visibility`.
- **title:** `guide_title`, `journey_title` or `content_title`.
- **locator:** `content_url` or `source_document`, the URL or content key the resource was loaded from.
- **content type:** `content_type`.
- **action:** the event's own verb, where it has one: `action`, `target_action`, `completion_method`, `completion_source` or `link_type`.
- **location:** `interaction_location`, the UI control or area the user acted in.
- **launch / surface:** `surface`, `launch_source` or `trigger_source`.
- **step / section:** `step_id`, `section_id`, `section_title`.
- **block progress:** `block_position`, `total_block_count`, `completable_block_count` (see [Block properties](TELEMETRY.md#block-properties)).
- **progress %:** `completion_percentage`, read with its rule-version property.
